# 黄白线指标调整
## 斜率与变化率
当前黄白线只是作为B1的附属指标, 实际上知行趋势指标适用于判断趋势的. 
趋势是当天数值, 对比前一天或前几天的变化率得到的.
今天的白线-昨天的白线 < 0 说明在下降, 同理黄线一样.
应该计算 current_白 - previous_白, 作为趋势.

## 黄白线上穿识别
    if  current_黄白线相等 || current_白 > current_黄
        if previous_白 < previous_黄
            说明发生白线上穿, 是重要指标

    if  current_黄白线相等 || current_白 < current_黄
        if previous_白 > previous_黄
            说明白线下穿黄线, 转为弱势, 也是重要风险

但是,黄白线可能贴的很紧频繁上下穿, 应该只考虑斜率大的时候

## 黄线的重要性
黄线应该看若干天(5天), 黄线向上说明中长期是向上的, 我们的B1都是大势(黄线) 逆小势, 黄线向下, 再怎么J < 0也没用

## 趋势拐点预测
    if current_白 - current_黄 < previous_白 - previous_黄
        if 白线>黄线 白线在上
            说明有向下拐的可能
        else
            说明有上穿可能
    
简而言之, 当白线>黄线, 当黄白线数值差变小, 说明上升趋势减弱可能向下拐头.
当 白线<黄线, 黄白线数值差变小, 说明拐头向上 可能上穿.
两个都是要识别的指标.

需要说明, 并不是所有的拐点都值得注意, 因为黄白线可能只是相互纠葛, 应该考虑两者相差很大的时候, 也就是拐头越大越值得注意.
## 白线加速识别
    if current_白 - current_黄 > previous_白 - previous_黄
        说明要么加速上行 要么加速下探

白线向上 且 斜率 > 黄线, 说明短期加速, 斜率越高, 越值得关注, 由于股价影响数值的大小, 应该综合考虑差值在黄白线数值本身的百分比.

可能是可以和上一个拐点识别一起做, 你可以判断一下 用白线的斜率 对比黄线的斜率, 或者用当前黄白差值 对比 前一天黄白差值, 是不是用起来差不多.

# 一、架构定位

知行趋势 = B1 的**前置过滤器 + 持仓管理工具**。趋势评价和B1买点完全独立。

B1 告诉你"这里可以买"，知行趋势告诉你"现在该不该看B1"和"要不要卖了"。两者平级，并行计算。

---

# 二、核心认知

### 黄白线物理特性

```
白线 = EMA(EMA(C,10),10)   → 双重平滑短期趋势 → 对价格敏感
黄线 = (MA14+MA28+MA57+MA114)/4  → 四合长期均线 → 变化极慢
```

由于公式物理特性，**几乎不存在"黄线上行、白线下行"的组合**。白线必然比黄线更早反应。状态分型应该以**黄白差值**为核心，而非各自方向去组合。

### 金叉是确认非转变

趋势萌芽期在**差值缩小→差值扩大**的拐点。金叉时趋势已确立，是"确认"而非"开始"。拐点是预警，穿越是确认。

### 空头≠放弃

- 差值<0(白在黄下) AND 黄线_5日斜率 > 0 → 短期回调中，B1值得看
- 差值<0 AND 黄线_5日斜率 < 0 → 真弱势，不建议参与
- 差值开始缩小 → 关注是否即将金叉 → 金叉确认后B1可靠

### 当日值用[-1]，昨日用[-2]

Python数组`[-1]`=今天最新值，`[-2]`=昨天值。所有对比都要用`[-1] vs [-2]`。

# 三、信号体系

## 1. 趋势评分 (score: 0~10)

| 维度 | 满分 | 评分规则 |
|------|------|---------|
| 白线加速 | 3 | 白线当日斜率 > 0 +1；白线当日斜率 > 白线5日均斜率 +1；白线斜率 > 黄线斜率 +1 |
| 穿越确认 | 2 | 近3日内发生金叉(过滤后) +2 |
| 差值在扩大 | 2 | 差值绝对值今日>昨日(趋势强化) +1；差值/黄线 > 3% +1 |
| 拐头确认 | 2 | 差值由缩小转扩大(拐头完成) +2 |
| 黄线方向 | 1 | 黄线5日斜率 > 0 +1 |
| **惩罚** | | 差值/黄线 < 0.5%(贴线纠葛) -2；差值/黄线 > 8%(极端偏离) -1 |

核心逻辑：**加速 > 穿越 > 拐头 > 差值扩大 > 黄线方向**。

## 2. 斜率信号 (slope)

```
白_当日斜率  = (白[-1] - 白[-2]) / 白[-2] * 100        # 今日白线变化率  
白_5日斜率  = (白[-1] - 白[-6]) / 白[-6] * 100        # 白线5日趋势
黄_5日斜率  = (黄[-1] - 黄[-6]) / 黄[-6] * 100        # 黄线5日趋势

白加速      = 白_当日斜率 > 白_5日均值                 # 白线今日加速
黄加速      = 黄_5日 > 黄_10日                         # 黄线长期加速
```

## 3. 穿越信号 (cross)

```
# 用当日值判断，不延迟
金叉: 白[-1] > 黄[-1] AND 白[-2] <= 黄[-2]
死叉: 白[-1] < 黄[-1] AND 白[-2] >= 黄[-2]
```

过滤假穿（贴线纠葛）：
```
|白[-1] - 黄[-1]| / 黄[-1] > 0.5%       # 差值至少0.5%
AND 金叉后差值在扩大(=确认趋势)           # 不是一闪而过
```

## 4. 拐点信号（预警，早于穿越）

```
差值[-1] = 白[-1] - 黄[-1]
差值[-2] = 白[-2] - 黄[-2]

差值缩小: |差值[-1]| < |差值[-2]|     → 趋势减弱
差值扩大: |差值[-1]| > |差值[-2]|     → 趋势加速

差值增长率 = (|差值[-1]| - |差值[-2]|) / |差值[-2]| * 100
```

拐点判断：
```
if 差值>0(多头格局) and 差值缩小:         → "多头减弱预警"
if 差值<0(空头格局) and 差值缩小:         → "空头收敛,可能拐头向上"
if 差值由缩小转为扩大(至少持续2日确认):    → "拐头完成确认"
```

有效拐点过滤：`|差值[-1]| / 黄[-1] > 1.5%`（排除贴线微调）

## 5. 偏离信号

| 指标 | 计算 | 阈值 |
|------|------|------|
| 价格偏离白线 | `|C - 白线| / 白线` | >5% 超买超卖 |
| 价格偏离黄线 | `|C - 黄线| / 黄线` | >10% 均值回归压力 |
| 白线偏离黄线 | `|白线 - 黄线| / 黄线` | >5% 趋势极端, <0.5% 纠葛 |

## 6. 趋势状态 (state)

| 状态 | 条件 | 含义 |
|------|------|------|
| bullish | 差值>0, 差值扩大, 黄线向上 | 强势多头，B1最可靠 |
| cautious | 差值>0, 差值缩小, 黄线向上 | 多头减速，注意拐头 |
| turning_up | 差值<0, 差值缩小, 黄线向上或走平 | 空头收敛，准备上穿 |
| weak_bearish | 差值<0, 差值扩大, 黄线向下 | 真空头，别碰 |
| neutral | 贴线纠葛 | 无明确趋势 |

### 注意

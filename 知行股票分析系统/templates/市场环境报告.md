# 市场环境报告模板

## 报告元信息
- **生成时间**: YYYY-MM-DD HH:MM
- **数据日期**: 最近交易日（凌晨执行取前一日）
- **数据覆盖**: {stock_count}只股票 / {index_count}个指数
- **数据源链**: 掘金MyQuant → 腾讯 → baostock → Tavily → LLM(DeepSeek)

---

## 结构定义（6 Section，按顺序输出）

### Section 1 → 大势研判

**代码预计算喂入数据（LLM 不得编造）：**
```
1. 指数行情表
   | 指数 | 收盘 | 涨跌% | 5日均量 | 今日量 | 量比 |
   |------|------|-------|---------|--------|------|

2. 全市场概览
   - 上涨家数 / 下跌家数 / 平盘家数（如有）
   - B1全景: 活跃{n}只 | 近B1{n}只 | 近B1占比{n}%
   - 与前次扫描对比: B1活跃 +{n}/-{n}, 近B1 +{n}/-{n}

3. 成交额（如有来源）
```

**LLM 输出要求：**
- 必含：指数分化的结构解读（大盘 vs 中小创 vs 科创 — 谁在扛、谁在砸）
- 必含：量能判断（放量杀跌 / 缩量调整 / 放量突破），与近5日均量对比
- 必含：一句话定性（≤30字），放在段首或段尾
- 长度：≥3段

---

### Section 2 → 主线板块

**代码预计算喂入数据：**
```
1. 板块B1密度 Top15（证监会行业分类，按B1数降序）
   | 板块 | B1数 | 较前次增减 | 板块涨跌% |
   |------|------|-----------|-----------|

2. WebSearch 补充（Tavily）
   - 市场热点新闻（如有）
   - Top3板块深度新闻（如有）
```

**LLM 输出要求：**
- 必含：主线是否延续 or 切换的判断 + 数据依据（B1增减、板块涨跌）
- 必含：新冒头板块的驱动逻辑推测（结合 WebSearch）
- 必含：板块内部分化描述（龙头抗跌 vs 跟风补跌）
- 长度：≥3段

---

### Section 3 → 关注变化

**代码预计算喂入数据：**
```
1. 新进B1列表（代码+名称+所属板块+J值）
2. 消失B1列表（代码+名称）
3. 趋势状态转移
   - 弱势→拐头向上: {n}只
   - 出现金叉: {n}只
   - 拐头→多头确认: {n}只
   - 多头→谨慎预警: {n}只
4. 缩量蓄爆信号: {n}只（列表）
```

**LLM 输出要求：**
- 必含：变化的方向性解读（整体好转 / 恶化 / 分化）
- 必含：2-3个代表性标的点名（代码+名称+变化原因）
- 长度：≥2段

---

### Section 4 → 持仓分析

**代码预计算喂入数据：**
```
1. 账户总览
   | 总资产 | 可用资金 | 股票市值 | 仓位% | 未实现盈亏 | 已实现盈亏(30日) |
   |--------|----------|----------|-------|-----------|-----------------|

2. 持仓明细（当前持有，按市值降序）
   | 代码 | 名称 | 成本 | 现价 | 盈亏% | 股数 | 市值 | 策略 | J值 | B1状态 | 趋势 |

3. 持仓行业分布
   | 行业 | 持仓市值 | 占比 | 行业今日涨跌 |
   |------|---------|------|------------|

4. 需关注的风险仓位
   - J<20 且浮亏的持仓
   - 趋势转弱（多头→谨慎 or 拐头向下）的持仓
   - 单行业集中度 > 30% 的持仓
```

**LLM 输出要求：**
- 必含：整体仓位健康度评估（仓位是否合理、盈亏结构是否健康）
- 必含：持仓与今日主线的对齐分析（你的票在不在主线上，要不要调）
- 必含：风险仓位点名 + 建议操作方向
- 必含：结尾固定 "> 不构成投资建议。"
- 长度：≥3段

---

### Section 5 → 风险提示

**代码预计算喂入数据：**
```
1. WebSearch 宏观/政策/地缘新闻
2. 科技拥挤度 = 科创50涨跌% × B1科技板块占比（交叉验证）
3. 近B1暴增预警: 若近B1较前次 +{n}%且绝对值 > 1000 → 触发
4. 历史季节性规律（如有 market_journal 历史）
```

**LLM 输出要求：**
- 必含：≥3条具体风险，每条有数据支撑
- 必含：每条风险的风险等级标注（高/中/低）
- 长度：≥3段

---

### Section 6 → 明日关注

**无额外喂入数据，LLM 基于前5节推断。**

**LLM 输出要求：**
- 必含：3-5个具体观察点
- 必含：每个观察点的触发条件（"若XX则YY"）
- 必含：结尾固定 "> 不构成投资建议。"
- 长度：≥3段

---

## 输出约束

1. **只输出 Section 2-6 的正文**（从 `## 一、...` 到 `## 六、...`）。`# 一级标题` 和元信息行由代码拼接，不要重复输出。
2. **禁止 Fabrication**：所有数字必须来自喂入数据，不得编造数据。如果没有某数据，写"数据暂缺"。
3. **角色语气**：资深A股策略分析师，客观理性，不喊口号，不吹票。
4. **结尾**：报告最末尾必须包含 `> 不构成投资建议。`

---

## 使用方式

CLI 命令：
```bash
python cli.py market-report              # 完整报告（含 WebSearch + LLM）
python cli.py market-report --no-search  # 跳过 WebSearch（更快）
python cli.py market-report --no-llm     # 只出数据表格，不调 LLM
python cli.py market-report --publish    # 生成后立即发布到飞书
```

# 知行指标使用说明

## 1. 知行趋势指标（白黄线）

通过 EMA 双平滑和多条均线平均，构建短中期趋势判断系统。

| 指标 | 公式 | 颜色 | 含义 |
|------|------|------|------|
| 白线（短期趋势） | EMA(EMA(C,10),10) | 白色 | 短期灵敏趋势线 |
| 黄线（多空线） | (MA14+MA28+MA57+MA114)/4 | 黄色 | 中长期多空分界 |

**判断规则**：
- 白线 > 黄线 → 短期强于中期，多头格局
- 白线 < 黄线 → 短期弱于中期，空头或震荡
- 黄线向上 → 中长期走强；黄线向下 → 中长期走弱
- 所有B1信号的前提条件：**白线 > 黄线（做上涨趋势）**

## 2. 单针下20

通过 3 日短期 K 线和 21 日长期 K 线的归一化数值（0-100），判断洗盘和超卖信号。

| 信号 | 条件 | 含义 |
|------|------|------|
| 单针下20 | 短期K ≤ 20 且 长期K ≥ 75 | 短线洗到位，中线仍强势 |
| 双线归零 | 短期K ≤ 6 且 长期K ≤ 6 | 极罕见，极致超卖，反弹概率极高 |

**注意**：单针下20 ≠ 立即买入，需结合趋势线和成交量确认。

## 3. 知行超级B1（7种买点）

在上涨趋势中寻找回调缩量买点。核心逻辑：**趋势股回调到关键位置 + KDJ/RSI超卖 + 缩量**。

| 信号 | 颜色 | 场景 | 条件要点 |
|------|------|------|---------|
| 超卖缩量B1 | 红色 | 严重超卖+缩量 | J<14，缩量明显，趋势向上 |
| 超卖缩量拐头B1 | 黄色 | RSI从极低位拐头 | 昨天RSI<20，今天开始拐头 |
| 超卖超缩量B1 | 青色 | 地量见地价 | 远期振幅>45%，超级缩量 |
| 原始B1 | 白色 | 超卖十字星 | J<13，小实体K线接近白线 |
| 回踩白线B1 | 紫色 | 强趋势股回调到白线 | 强趋势股，回踩缩量获支撑 |
| 回踩白线超级B1 | 绿色 | 超牛股回调 | BBI持续向上，假跌破后收回 |
| 回踩黄线B1 | 短黄 | 深度回调到黄线 | J<13更严格要求，MA60向上 |

**信号优先级**：
- 彩色柱同时出现多个 → 共振，优先级最高
- 红色/黄色/青色 → 左侧埋伏型（超卖止跌）
- 紫色/绿色/短黄 → 右侧确认型（回调支撑）
- 信号出现但振幅过大（>8%主板/11%创业板）或有大绿棒 → 可靠性下降

## 4. 基础B1（B1B2B3 三级递进）

基于 KDJ 超卖的三级递进式选股：B1发现 → B2验证 → B3确认。

| 信号 | 条件 | 含义 |
|------|------|------|
| B1 | J<13 + 成交额充足 + 白线>黄线 | 发现超跌标的，列入观察 |
| B2 | 昨天B1 + J<80 + 涨幅>3.9% + 放量 | 资金确认进场，可以追 |
| B3 | 昨天B2 + 缩量 + 振幅≤2% | 大涨后缩量洗盘，筹码锁定 |

**递进关系**：B1→B2→B3 缺一环就断链。和知行超级B1的区别：
- 基础B1 → 右侧追涨确认
- 知行超级B1 → 左侧回调埋伏

## 5. 持股评分（0-5分）

| 扣分项 | 含义 |
|--------|------|
| 今日下跌 | C < ref(C,1) |
| 放量下跌 | V > ref(V,1) 且下跌 |
| 破白线 | C < 白线 |
| KD死叉 | J下穿D |
| 趋势转弱 | 白线向下 |

- 5分 → 安心持有
- 3-4分 → 警惕，考虑减仓
- 0-2分 → 考虑离场

## 6. 缩爆B1

识别"爆量+缩量"的量价模式。

算法：找到爆量日(量比>均量3倍+收阳) → 次日必须缩量收跌 → 追踪缩量天数 → 再次爆发或跌破支撑。

| 状态 | 含义 |
|------|------|
| 观察中(is_active=true) | 缩量≥3天未爆发，候选埋伏 |
| 已爆发(is_active=false) | 缩量后再次放量涨>5%，已确认 |

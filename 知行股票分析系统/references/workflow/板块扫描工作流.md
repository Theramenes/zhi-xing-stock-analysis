# XX板块/概念板块分析工作流

## 用户提示词
- "扫描XXX行业的情况" 或 "扫描XXX概念股分布" 或 "扫描XXX相关股票" 或 "扫描XXX板块最近走势,有没有走出来"
  - 用户只提到"板块""概念""行业",没有提及"个股", 应该只进行板块情况汇总
- "扫描XXX板块相关股票寻找交易机会" "找一下XX行业的B1"
  - 用户提到 "B1","交易机会", 则需要进行个股指标分析

## 一. 板块定位
### 情况1. 指定扫描
1. 如果 用户明确说了行业板块, 则去ifind数据源获取行业列表;
2. 如果 用户明确说了概念, 去ifind找概念;
3. 如果 用户两个都提到, 只去找行业, 不要找大量概念股

* **如果得到的板块是一级行业, 则在同级的时候按照细分行业分类输出**

### 情况2. 模糊匹配
没有指定扫描, 或者给出的条件模糊, 则可以从同花顺获取所有细分行业, 匹配可选的让用户确认, 除非有非常关联的, 不然需要确认才继续

## 二. 板块分析流程
1. 统计板块近3,5日走势
2. 统计板块资3,5日金流动情况
3. 统计板块内个股涨跌停家数情况
4. 统计板块内核心标的/龙头标的, 统计今日出现异动的标的

如果是搜索概念股, 

## 三. 板块个股分析流程
只有当用户说到"找B1" "个股"的时候, 才触发板块个股遍历分析
1. 遍历所有板块内个股
    - 套用知行指标计算,计算B点
    - 查询资金异动情况
    - 评价与评分
    - 历史数据对比(自身缓存, 若有)
2. 统计B1, 接近B1, 缩量蓄爆的票. 将他们在本地保存以便后续追踪
3. 以行业相关度 + 行业板块内重要度 + 是否B1接近B1, 得分从高到低排列, 作表格汇总

## 四. 汇总结果输出文档
1. 生成md文档, 存本地文档 `data/reports/local_markdown/XX扫描_YYYYMMDD_hhmm.md`
2. 将核心标的/B1标的/近b标的票保留为raw date, 只标记股票代码, 存本地 `data/YYYY-MM-DD/B1_candidate.json`
3. 按照格式创建云文档, 存入飞书**知识库**

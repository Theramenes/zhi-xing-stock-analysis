# 黄白线指标调整
## 斜率与变化率
当前黄白线只是作为B1的附属指标, 实际上知行趋势指标适用于判断趋势的. 
趋势是当天数值, 对比前一天或前几天的变化率得到的.
今天的白线-昨天的白线 < 0 说明在下降, 同理黄线一样.
应该计算 current_白 - previous_白, 作为趋势.

## 黄白线上穿识别
    if  current_黄白线相等 || current_白 > current_黄
        if previous_白 < previous_黄
            说明发生白线上穿, 是重要指标

    if  current_黄白线相等 || current_白 < current_黄
        if previous_白 > previous_黄
            说明白线下穿黄线, 转为弱势, 也是重要风险

但是,黄白线可能贴的很紧频繁上下穿, 应该只考虑斜率大的时候

## 黄线的重要性
黄线应该看若干天(5天), 黄线向上说明中长期是向上的, 我们的B1都是大势(黄线) 逆小势, 黄线向下, 再怎么J < 0也没用

## 趋势拐点预测
    if current_白 - current_黄 < previous_白 - previous_黄
        if 白线>黄线 白线在上
            说明有向下拐的可能
        else
            说明有上穿可能
    
简而言之, 当白线>黄线, 当黄白线数值差变小, 说明上升趋势减弱可能向下拐头.
当 白线<黄线, 黄白线数值差变小, 说明拐头向上 可能上穿.
两个都是要识别的指标.

需要说明, 并不是所有的拐点都值得注意, 因为黄白线可能只是相互纠葛, 应该考虑两者相差很大的时候, 也就是拐头越大越值得注意.
## 白线加速识别
    if current_白 - current_黄 > previous_白 - previous_黄
        说明要么加速上行 要么加速下探

白线向上 且 斜率 > 黄线, 说明短期加速, 斜率越高, 越值得关注, 由于股价影响数值的大小, 应该综合考虑差值在黄白线数值本身的百分比.

可能是可以和上一个拐点识别一起做, 你可以判断一下 用白线的斜率 对比黄线的斜率, 或者用当前黄白差值 对比 前一天黄白差值, 是不是用起来差不多.

# 知行趋势指标 — 实施 Plan

## 一、架构定位

知行趋势指标 = B1 的**前置过滤器 + 持仓管理工具**。

```
选股端:
  知行趋势 → 过滤出趋势向上的票 → B1 → 确认买点 → 缩量爆发 → 确认底部

持仓端:
  知行趋势 → 每天更新状态 → 趋势变化 → 持有/减仓/离场
```

B1 告诉你"这里可以买"，知行趋势告诉你"现在该不该看B1"和"要不要卖了"。两者平级，并行计算。

## 二、信号体系

### 1. 趋势状态 (state)

| 状态 | 白线 | 黄线 | 白vs黄 | 含义 |
|------|------|------|--------|------|
| 强势多头 | ↑ | ↑ | 白>黄 | 最佳状态，B1信号可信度最高 |
| 多头调整 | ↓或→ | ↑ | 白<黄 | 短期回调，B1可看但要等白线重新向上 |
| 多空转折 | ↑（刚穿越） | ↑ | 刚金叉 | 趋势转变，重要信号 |
| 弱势空头 | ↓ | ↓ | 白<黄 | 黄线向下不看B1 |
| 空头反弹 | ↑ | ↓ | 白>黄 | 假反弹，黄线向下不参与 |

### 2. 斜率信号 (slope)

- **白线斜率_1日**: `(白[-1] - 白[-2]) / 白[-2] * 100` — 短期动量
- **白线斜率_5日**: `(白[-1] - 白[-6]) / 白[-6] * 100` — 短期趋势
- **黄线斜率_5日**: `(黄[-1] - 黄[-6]) / 黄[-6] * 100` — 中长期方向
- **白线加速**: `白线斜率_5日 - 黄线斜率_5日 > 阈值` — 短期加速信号

### 3. 穿越信号 (cross)

```python
# 金叉: 白线上穿黄线
if 白[-1] > 黄[-1] and 白[-2] < 黄[-2]:
    # 过滤假穿越: 斜率太小(贴线纠葛)不算
    if abs(白线斜率_1日) > 0.1 and abs(黄白差值/黄线) > 0.005:
        signal = "金叉"

# 死叉: 白线下穿黄线  
if 白[-1] < 黄[-1] and 白[-2] > 黄[-2]:
    if abs(白线斜率_1日) > 0.1 and abs(黄白差值/黄线) > 0.005:
        signal = "死叉"
```

### 4. 拐点信号 (inflection)

```python
# 差值收敛 = 趋势减弱, 差值扩大 = 趋势加速
diff_now = 白[-1] - 黄[-1]
diff_prev = 白[-2] - 黄[-2]

if 白[-1] > 黄[-1]:  # 多头格局
    if diff_now < diff_prev:      # 差值缩小 → 顶部预警
        signal = "上升趋势减弱,可能拐头"
    elif diff_now > diff_prev:     # 差值扩大 → 加速
        signal = "上升趋势加速"

if 白[-1] < 黄[-1]:  # 空头格局
    if diff_now > diff_prev:      # 差值缩小(负值变大) → 底部预警
        signal = "下跌趋势减弱,可能拐头向上"
    elif diff_now < diff_prev:     # 差值扩大 → 加速下跌
        signal = "下跌趋势加速"
```

拐点的有效性判断: `abs(diff_now) / 黄[-1] > 阈值%` 才报警, 避免贴线纠葛时的假信号。阈值建议 1.5%-3%。

### 5. 偏离信号 (deviation)

| 指标 | 计算 | 含义 |
|------|------|------|
| 价格偏离白线 | `abs(C - 白线) / 白线 * 100` | 短期超买超卖 |
| 价格偏离黄线 | `abs(C - 黄线) / 黄线 * 100` | 均值回归压力 |
| 白线偏离黄线 | `abs(白线 - 黄线) / 黄线 * 100` | 趋势极端度(>5%=注意反转) |

### 6. 综合评分 (score) — 0~10分

| 条件 | 加分 | 理由 |
|------|------|------|
| 黄线_5日斜率 > 0 | +3 | **最核心**: 大势向上 |
| 白线 > 黄线 | +2 | 多头排列 |
| 白线_1日斜率 > 0 | +1 | 短期向上 |
| 白线_5日斜率 > 0 且 > 黄线_5日斜率 | +1 | 白线加速上行 |
| 差值扩大(顺势方向) | +1 | 趋势强化 |
| 刚发生金叉 | +2 | 趋势转折成立 |
| 黄线_5日斜率 < -0.5% | **-3** | 大势已去强扣分 |
| 刚发生死叉 | **-3** | 风险信号 |
| 白线_1日斜率 < -1% | -1 | 短期急跌 |

评分解读: ≥6 = 趋势良好可积极B1, 3-5 = 谨慎观望, <3 = 不建议B1买入

### `indicators/trend_analyzer.py` (~200行)

```python
class TrendAnalyzer:
    """知行趋势指标 — 黄白线独立分析"""
    
    def __init__(self, code, candles):
        self.code = code
        c = candles[-122:]  # 120天K线 + 2天缓冲
        self.C = [v['close'] for v in c]
        self.n = len(self.C)
        
        # 白线 = EMA(EMA(C,10),10)
        self.白线 = self._double_ema(10)
        # 黄线 = (MA14+MA28+MA57+MA114)/4
        self.黄线 = self._composite_ma()
    
    def compute(self) -> dict:
        return {
            "code": self.code,
            "白线": round(self.白线[-1], 3),
            "黄线": round(self.黄线[-1], 3),
            "state": self._state(),           # 趋势状态
            "slope": self._slope(),            # 斜率
            "cross": self._cross(),            # 穿越信号
            "inflection": self._inflection(),  # 拐点信号
            "deviation": self._deviation(),    # 偏离信号
            "score": self._score(),            # 综合评分
            "signals": self._signals(),        # 触发信号列表
        }
```

## 四、两个值得讨论的问题

### 白线斜率对比黄线差值？

你的文档里两个思路:
1. 用白线斜率 vs 黄线斜率
2. 用黄白差值 vs 前一天差值

我倾向**两个都要**: 斜率判断各自的方向和速度（独立属性），差值判断两者间的关系。不冲突，两个维度:

| 情景 | 白_斜率 | 黄_斜率 | 差值变化 | 判断 |
|------|---------|---------|----------|------|
| 强势多头 | +0.5% | +0.2% | 扩大 | 最佳 |
| 多头减速 | -0.1% | +0.2% | 缩小 | 警惕 |
| 多头转空 | -0.5% | -0.1% | 缩小→负 | 离场 |
| 空头加速 | -1.0% | -0.3% | 扩大(负) | 远离 |

### 白线的双重EMA是否够用？

当前 `EMA(EMA(C,10),10)` 已经做了两次平滑，白线本身对股价波动有很强的过滤。不需要再额外加平滑。如果改成 `EMA(EMA(C,5),10)` 会让白线更贴近股价，信号更灵敏但假信号更多。建议保持现有参数不变。

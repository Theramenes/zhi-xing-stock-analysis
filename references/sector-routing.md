# 板块查询路由规则

## 数据源层级

同花顺 iFind 提供两层板块分类：

| 层级 | 结构 | 粒度 | 示例 | 成分股数 |
|------|------|------|------|---------|
| 同花顺行业 | 三级树 `一级-二级-三级`，每只股票挂一个叶子节点 | 精确定位，适合行业轮动 | `电力设备-电池-锂电池` | 32-408 |
| 同花顺概念 | 扁平标签，一只股票可挂多个概念 | 题材覆盖，适合概念扫描 | `锂电池概念` | 590 |

## 行业层级树（与锂电池/电池相关）

```
电力设备（一级）
├── 电池（二级）
│   ├── 锂电池                          ← 三级：电芯/电池厂
│   ├── 锂电专用设备                    ← 三级：正极/负极/隔膜设备
│   ├── 电池化学品                      ← 三级：电解液/六氟磷酸锂
│   └── 其他电池
├── 光伏设备 → 光伏电池组件 / 硅料硅片 / 逆变器 / 光伏辅材 / 光伏加工设备
├── 电网设备 → 电气自控设备 / 输变电设备 / 线缆部件及其他
├── 风电设备 → 风电整机 / 风电零部件
└── 电机 / 其他电源设备

有色金属（一级）
└── 能源金属（二级）
    ├── 锂                               ← 上游矿企
    ├── 钴
    └── 镍
```

## iFind 查询语法

```
endpoint-call a_share_common_query
  --payload {"searchstring": "<查询>", "searchtype": "stock|plate"}

searchtype=stock: 返回个股级别数据，适合获取行业分类+资金流+龙头标记
searchtype=plate: 返回板块级别数据，适合获取概念成分股+概念解析+资讯
```

### 实测效果

**关键发现**：iFind 对层级路径做的是**前缀匹配**，不是精确过滤。
- `"电力设备-电池"` → 前缀匹配到 `电力设备*`，返回整个一级行业 408 只 ❌
- `"电池行业"` → 自然语言理解，精准返回电池二级行业 105 只 ✅

| 用户口语 | iFind searchstring | 返回行数 | 实际范围 |
|---------|-------------------|---------|---------|
| "锂电池行业" | `锂电池行业` | 32 | 电力设备-电池-锂电池（纯正电池厂） |
| "电池行业" | `电池行业` | 105 | 电力设备-电池（4个三级子行业合计） |
| "锂电专用设备" | `锂电专用设备行业` | ? | 待验证 |
| "电池化学品行业" | `电池化学品行业` | ? | 待验证 |
| "能源金属行业" | `能源金属行业` | ? | 有色金属-能源金属（锂钴镍） |
| "锂电池概念" | `锂电池概念` | 590 | 概念全量（跨行业） |
| "固态电池概念" | `固态电池概念` | 291 | 概念全量 |

**关键规则**：行业查询用口语 `"{名称}行业"`（不用层级路径），概念查询用 `"{名称}概念"`。

## 用户查询路由规则

### 决策树

```
用户输入
  │
  ├─ 含 "行业"/"板块"（不含"概念"）
  │    → 同花顺行业层级
  │    → 用户词汇 → 层级路径映射（见下方映射表）
  │
  ├─ 含 "概念"
  │    → 同花顺概念
  │    → "{用户词}概念" 直接查询
  │
  ├─ 含糊（如"锂电池"，未指定行业/概念）
  │    → 默认走概念（覆盖更广）
  │    → 同时提示用户可指定行业："电力设备-电池-锂电池有32只纯正标的"
  │
  └─ 含 "B1"/"交易机会"/"买点"/"信号"
       → 触发个股知行指标扫描
       → 不含 → 仅板块概览（走势/资金流/龙头/新闻）
```

### 用户词汇 → iFind searchstring 映射

**行业查询用口语 `"{名称}行业"`，概念查询用 `"{名称}概念"`**

| 用户说 | 类型 | searchstring | 约返回 |
|--------|------|-------------|--------|
| 锂电池/锂电/电池 | 行业 | `电池行业` | ~105 只 |
| 锂电设备 | 行业 | `锂电专用设备行业` | 20 |
| 电池化学品/电解液 | 行业 | `电池化学品行业` | 42 |
| 锂矿/锂资源 | 行业 | `能源金属行业` | 12（锂钴镍，需本地过滤纯锂） |
| 光伏 | 行业 | `光伏设备行业` | 73 |
| 芯片/半导体 | 行业 | `半导体行业` | 179 |
| 电网/输变电 | 行业 | `电网设备行业` | 139 |
| 机器人 | 行业 | `机器人行业` | 21 |
| 固态电池 | 概念 | `固态电池概念` | 291 |
| 锂电池（概念） | 概念 | `锂电池概念` | 590 |
| AI/人工智能 | 概念 | `AI应用概念` | 概念级 |
| 钠电池 | 概念 | `钠离子电池概念` | 概念级 |
| 新能源汽车 | 行业+概念 | 先行业 `汽车行业`→过滤整车 + 概念 `新能源汽车概念` | ~汽车全量 |

**子行业过滤**：iFind 不支持精确子行业过滤。如需只取三级行业（如只要"锂电池"不要"电池化学品"），取上级行业全量后本地按 `所属同花顺行业` 字段筛选。

### 歧义处理

| 用户输入 | 歧义 | 处理 |
|---------|------|------|
| "扫锂电池" | 行业(32只) or 概念(590只)? | 先问：查"锂电池行业"还是"锂电池概念"？默认走概念 |
| "扫电池" | 二级行业？ | 展开为"电力设备-电池"（含4个三级子行业） |
| "锂电板块" | "板块"可能指行业/概念 | 视为行业查询 |

## 板块概览 vs 个股扫描

```
含B1/买点/交易机会/信号 → scan-sector-b1:
  ① iFind 查成分股（行业路径 or 概念名）
  ② 20线程 iFind 取K线
  ③ b1_calculator 全量计算
  ④ 分类排序 → 报告

不含以上关键词 → scan-sector-overview:
  ① iFind 查成分股 + 资金流 + 龙头 + 概念解析（带这些字段）
  ② 本地聚合：板块均涨跌 / 总资金流向 / 龙头识别
  ③ freeStockLine 补新闻/公告
  ④ 板块走势描述 → 报告
```

## 多板块支持

用户空格分隔多个查询词时，逐一展开：
- "锂电 光伏 芯片" → 3个行业分别扫描
- "固态电池 钠电池" → 2个概念分别扫描
- "锂矿 锂电池" → 1个行业(能源金属) + 1个概念(锂电池概念)

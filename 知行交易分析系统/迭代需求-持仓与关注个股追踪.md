# 持仓与关注个股追踪 — 操作手册

## 环境

```bash
cd 知行交易分析系统/scripts
```

所有命令通过 `python cli.py` 执行。数据存储在 `data/kline.db` 中。

---

## 持仓管理

### 新增持仓

```bash
python cli.py holdings-add \
  --code <股票代码> \
  --cost <成本价> \
  --qty <持仓数量> \
  [--name 股票名称] \
  [--strategy 长线|短线|波段|套利] \
  [--notes 备注] \
  [--stop-loss 止损价] \
  [--target 目标价]
```

示例：
```bash
# 首次建仓
python cli.py holdings-add --code 002460 --name 赣锋锂业 --cost 45.2 --qty 1000 --strategy 长线

# 加仓后更新（重新执行，成本价和数量会被覆盖）
python cli.py holdings-add --code 002460 --cost 45.5 --qty 1500 --notes 加仓500股
```

### 查看持仓

```bash
python cli.py holdings-list            # 简略
python cli.py holdings-list --verbose  # 含首次买入日期、最后交易、备注
```

### 记录交易流水

```
方向说明：
  buy    建仓/加仓
  sell   减仓/卖出
  t_buy  做T买入
  t_sell 做T卖出
  clear  清仓
```

```bash
python cli.py transaction-add \
  --code <股票代码> \
  --direction buy|sell|t_buy|t_sell|clear \
  --price <成交价> \
  --qty <数量> \
  [--date 2026-05-20] \
  [--reason 交易理由] \
  [--memo 备注]
```

示例：
```bash
# B1信号建仓
python cli.py transaction-add --code 002460 --direction buy --price 45.2 --qty 500 --reason "拐头B信号"

# 做T卖出
python cli.py transaction-add --code 002460 --direction t_sell --price 46.8 --qty 200 --reason "做T止盈"

# 止损清仓
python cli.py transaction-add --code 002460 --direction clear --price 42.0 --qty 1500 --reason "跌破止损线"
```

> 交易记录会自动更新持仓的成本价和数量：买入加权平均成本，卖出计算实现盈亏。

### 查看交易流水

```bash
python cli.py transaction-list                      # 全部，近90天
python cli.py transaction-list --code 002460        # 按股票
python cli.py transaction-list --days 180           # 近半年
```

## 关注列表

### 加入关注

```bash
python cli.py watchlist-add \
  --code <股票代码> \
  [--name 股票名称] \
  [--reason 关注原因] \
  [--priority 1|2|3|4|5] \     # 1=最高优先级
  [--tags '["标签1","标签2"]'] \
  [--price 添加时价格] \
  [--notes 备注]
```

示例：
```bash
# 在板块扫描中发现龙头，手动加入
python cli.py watchlist-add --code 300750 --name 宁德时代 --reason 锂电池龙头 --priority 1

# 带标签
python cli.py watchlist-add --code 002460 --name 赣锋锂业 \
  --reason 回踩黄线B --priority 2 --tags '["锂电池","B1观察","上游"]'
```

> 注意：`scan-sector-b1` 扫描出的 B1/近B1 票会**自动入库**到关注列表（`source=auto_scan`），无需手动 add。加 `--no-auto-save` 可跳过。

### 查看关注

```bash
python cli.py watchlist-list                     # 活跃的关注票
python cli.py watchlist-list --status observing  # 观察期中（B1消失不久）
python cli.py watchlist-list --status archived   # 已移出归档
python cli.py watchlist-list --status all        # 全部
```

### 移出关注

```bash
python cli.py watchlist-remove --code 300750 --reason "已建仓"
# 状态变为 archived，不移出表
```

## 日终追踪

每天收盘后跑一次，拉关注票和持仓票的最新K线，算知行指标，更新状态。

```bash
python cli.py daily-review                           # 仅追踪关注+持仓票
python cli.py daily-review --sector 电池,锂电池      # 额外扫描指定板块
python cli.py daily-review --sector 电池 --workers 20 # 20线程并行
python cli.py daily-review --output report.json      # 保存JSON摘要
```

## B1 状态追踪

查看某只票从发现到离场的完整状态历程。

```bash
python cli.py b1-tracking --code 002460            # 最近30条
python cli.py b1-tracking --code 002460 --limit 60 # 最近60条
```

输出示例：
```
=== B1追踪: 002460 (12条) ===
  2026-05-12 stage=watching      J= 35 score=2 days=3
  2026-05-13 stage=near_b1       J= 18 score=2 days=1
  2026-05-14 stage=b1            J= 10 score=4 days=1  watching→b1
  2026-05-15 stage=b1            J=  8 score=4 days=2
  2026-05-16 stage=observing     J= 42 score=2 days=1  b1→observing
  ...
```

### 状态说明

| Stage | 含义 | 触发条件 |
|-------|------|---------|
| `watching` | 关注中，无信号 | 加入关注列表初始状态 |
| `near_b1` | 接近B1 | J < 20 但无B1信号 |
| `b1` | B1信号触发 | B1信号列表非空 |
| `observing` | B1消失观察期 | 从 b1 状态退出，7天缓冲 |
| `bought` | 已建仓 | 添加 transaction buy 后 |
| `holding` | 持仓中 | 建仓后持续监控 |
| `sell_candidate` | 建议卖出 | 趋势转空 + 无B1 + J>50 |
| `sold` | 已卖出 | 用户确认清仓 |
| `archived` | 已归档 | 观察期满/手动移出 |

## 重点板块

### 添加

```bash

  --name <板块名> \
  [--type industry|concept] \
```

```bash
python cli.py focus-sector-list                     # 活跃
```

## 板块扫描（增强）

`scan-sector-b1` 现在默认自动入库：

```bash
# 标准扫描 + 自动入库到关注列表和B1候选
python cli.py scan-sector-b1 --name 电池

# 禁止自动入库（仅出报告）
python cli.py scan-sector-b1 --name 电池 --no-auto-save

# 不发布飞书
python cli.py scan-sector-b1 --name 电池 --no-publish
```

自动入库逻辑：
- `b1_stocks` → `watchlist`(source=auto_scan) + `b1_candidate`(category=B1)
- `near_b1_stocks` → `watchlist`(source=auto_scan) + `b1_candidate`(category=near_B1)
- 已存在的票会被更新（不重复插入）

## 常用组合操作流

### 场景A：新手建仓

```bash
# 1. 扫板块，发现B1票（自动入库到关注列表）
python cli.py scan-sector-b1 --name 电池

# 2. 查看关注列表
python cli.py watchlist-list

# 3. 决定买入，记录交易
python cli.py holdings-add --code 002460 --name 赣锋锂业 --cost 45.2 --qty 1000 --strategy 长线
python cli.py transaction-add --code 002460 --direction buy --price 45.2 --qty 1000 --reason "拐头B+回踩白线B"

# 4. 从关注列表移除（因为已建仓）
python cli.py watchlist-remove --code 002460 --reason "已建仓"
```

### 场景B：每日收盘复盘

```bash
# 日终追踪（关注票+持仓票+额外扫重点板块）
python cli.py daily-review --sector 电池,机器人概念

# 查看持仓
python cli.py holdings-list --verbose

# 查看B1消失的票
python cli.py watchlist-list --status observing

# 查看某只票的完整追踪历史
python cli.py b1-tracking --code 002460
```

### 场景C：持仓调仓

```bash
# 加仓
python cli.py transaction-add --code 002460 --direction buy --price 44.8 --qty 500 --reason "J<10加仓"

# 做T
python cli.py transaction-add --code 002460 --direction t_sell --price 46.5 --qty 300 --reason "做T止盈5%"

# 减仓
python cli.py transaction-add --code 002460 --direction sell --price 47.0 --qty 200 --reason "轻仓止盈"

# 清仓
python cli.py transaction-add --code 002460 --direction clear --price 43.0 --qty 1000 --reason "趋势转空止损"
```
